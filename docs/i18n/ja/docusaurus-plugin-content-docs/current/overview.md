# AutoNyan のしくみ

AutoNyan は、共有された 1 つの Google Drive フォルダを「自動で整理される受信
箱」に変えます。書類を置くだけで、AutoNyan が中身を読み取り、置き場所を判断し、
ファイルし、何をしたかを知らせます。すべて自動で行われ、操作は不要です。

## 全体の流れ

監視対象のフォルダに書類を追加すると、次の 5 つのステップを通ります。

1. **検出** — AutoNyan は監視対象のフォルダを定期的に確認し、新しく追加された
   書類を見つけます。
2. **読み取り** — 各書類の中のテキストを抽出します。紙の書類をスキャンまたは
   撮影し、PDF として保存したものも対象です。
3. **分類** — 抽出したテキストをあなたのカテゴリと照合し、最も合うものを選び
   ます。
4. **整理** — 書類を該当するカテゴリフォルダへ移動し、そのフォルダの既存
   ファイルの命名に合わせた、内容がわかる名前にリネームします。うまく合う
   ものがなければ **未分類（Uncategorized）** フォルダへ元の名前のまま移す
   ので、書類が失われることはありません。
5. **通知** — 何が処理され、各書類がどのカテゴリに入り、内容がどのようなもの
   だったかをまとめたメールが届きます。

> **ファイルを置く → 検出 → 読み取り → 分類 → 整理 → メールが届く**

### カレンダーにも登録される書類 {#documents-that-also-go-on-a-calendar}

**カテゴリ**の中には、**カレンダー**が結び付けられているものがあります。
ステップ 3 で書類がそうしたカテゴリに分類されると、AutoNyan はステップ 2 で
読み取ったテキストから日付を拾い出し、そのカテゴリに設定されたカレンダーへ
1 件ずつ予定として登録し、その一覧をメールで知らせます。

カレンダーを選ぶのはカテゴリなので、この流れは**分類の後**に進みます。ただし
ステップ 4 を待つことはないため、**整理に失敗した場合でも**予定はカレンダーに
登録されます。一方で、分類が正しいことには依存します。AutoNyan が**確信を
持てなかった**書類は何も登録されず、*未分類*に入った書類も同様です。

> **…カレンダーが設定されたカテゴリの書類では: 分類 → 予定の登録 → メールが
> 届く**

すべてのカテゴリにカレンダーがあるわけではありません。どのカテゴリを予定の
対象とし、どのカレンダーに書き込むかは、AutoNyan を運用している担当者が決めて
います。自分のカテゴリが対象かどうか分からない場合は、その担当者に確認して
ください。カレンダーが結び付けられていないカテゴリの書類は、これまでどおり
分類・整理されるだけです。

想定しているのは、1 つの書類に多くの日付が含まれる場合 — たとえば 1 か月分の
予定が載った学校のおたより — で、それらを誰も手入力せずに済むようにするための
ものです。受け取るメールの内容は**[日常の使い方](./daily-use.md)**を参照して
ください。

## カテゴリはあなたが決める

AutoNyan が勝手にカテゴリを作ることはありません。カテゴリとは、Drive のカテゴリ
領域内に**あなたが作成したフォルダ**そのものです。たとえば `請求書`、`領収書`、
`契約書` などです。AutoNyan はフォルダ名を読み取り、各書類を合うものに振り分け
ます。新しいカテゴリを追加するにはフォルダを作り、不要になったら削除します。
整理の仕方はあなたが管理します。

## 変わらないこと

- これまでどおり Google Drive を使うだけです。
- 手作業で書類を振り分ける必要はありません。
- 元の書類は削除されず移動されるだけなので、カテゴリフォルダで必ず見つけられ
  ます。
